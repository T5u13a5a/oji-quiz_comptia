# おじさん問題集

CompTIA の **Security+（SY0-701）** と **Network+（N10-009）** の対策問題を、それぞれ500問ずつ収録した無料の問題集です。ブラウザで開くだけで使えます。

解説はすべて「おじさん構文」です。さらに全問に **📌本番の判断ポイント**（本番で選択肢を見分けるコツ）がついています。

👉 **[問題集を開く](https://ユーザー名.github.io/リポジトリ名/)**

| ページ | 内容 |
|---|---|
| [Security+](https://ユーザー名.github.io/リポジトリ名/secplus.html) | SY0-701・5分野・500問 |
| [Network+](https://ユーザー名.github.io/リポジトリ名/netplus.html) | N10-009・5分野・500問 |
| [みんなの集計](https://ユーザー名.github.io/リポジトリ名/dashboard.html) | 分野別の正答率・よく間違えられる問題 |

## 使い方

- 分野を選んで解くか、全分野からランダムに出題できます
- 解き終わるとすぐに正誤と解説が表示されます
- 成績はブラウザに保存されるので、次回は続きから解けます
- 間違えた問題だけを解き直すこともできます
- スマートフォンでも使えます

## IDとパスワード（任意）

各問題集ページの下から、IDとパスワードを登録できます。

- 登録すると、別の端末やブラウザでも同じ成績で続きから解けます
- 登録しなくてもすべての機能を使えます
- パスワードはそのまま保存しません。ハッシュ化した値だけを保存します

## 送信されるデータについて

「みんなの集計」を作るために、解答の結果を送信しています。

| 送るもの | 送らないもの |
|---|---|
| 問題番号・正誤・解答日時 | 名前・メールアドレス |
| ランダムに作られた端末ID | 選んだ選択肢 |
| ユーザーID（ログインした人だけ） | パスワード（ハッシュ化した値だけを保存） |

- **送信は止められます。** 各問題集ページの下にあるチェックを外すと、それ以降は何も送りません
- 集計ページに表示するのは全体の数字だけで、個人ごとの成績は表示しません
- **IDを登録した人の成績は、ID単位で管理者が見ることができます。** 気になる場合は登録せずに使ってください
